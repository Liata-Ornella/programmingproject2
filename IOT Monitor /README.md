# Project 3 — Dynamic IoT Event Monitoring and Callback Engine

## What the program does
This C program registers temperature, pressure and battery devices, stores them in a
dynamic array, generates simulated sensor readings, and sends each reading to the
correct callback function. It also has a custom sensor drift callback.

## Build and run
In the VS Code terminal, from this folder:

```bash
gcc -std=c11 -Wall -Wextra -pedantic main.c -o iot_monitor
./iot_monitor
```

## Operating limits and simulation ranges

| Device | Generated range | Normal operating range |
|---|---:|---:|
| Temperature | -5 to 50 C | 0 to 40 C |
| Pressure | 80 to 130 kPa | 90 to 110 kPa |
| Battery voltage | 3.0 to 4.5 V | 3.30 to 4.20 V |

The random number generator is initialized once in `main()` using `srand(time(NULL))`.

## Custom callback: sensor_drift_detector
The custom callback compares a device's current reading with its previous reading.
It raises a drift warning when the absolute change is greater than:
- 8 C for temperature devices
- 15 kPa for pressure devices
- 0.35 V for battery devices

The callback then saves the current reading so it can be used for the next comparison.
The first reading is saved as a baseline and does not trigger a drift warning.
This callback is dispatched through a `CustomCallback` function pointer.

## Callback dispatch
`process_device()` receives a pointer to a `Device` and a function pointer.
The selected callback is temperature_monitor, pressure_monitor or battery_monitor.
A second call dispatches sensor_drift_detector as the additional custom callback.

## Memory management
- The device list grows with `realloc()` when it becomes full.
- The device list shrinks after removals when usage becomes low.
- Duplicate IDs are rejected.
- Allocation is checked before the new pointer is stored.
- The device array is freed before the program exits.
